## Базовый набор команд Git для комфортной работы

### Базовые операции

1. **git init** — создание нового репозитория
2. **git clone** — клонирование существующего репозитория
3. **git status** — проверка состояния репозитория
4. **git add** — добавление файлов в индекс
5. **git commit** — создание коммита
6. **git log** — просмотр истории коммитов
7. **git branch** — управление ветками
8. **git checkout** — переключение между ветками
9. **git merge** — слияние веток
10. **git push** — отправка изменений в удаленный репозиторий
11. **git pull** — получение изменений из удаленного репозитория

### Продвинутые операции

12. **git stash** — временное сохранение изменений
13. **git rebase** — перемещение коммитов
14. **git reset** — отмена изменений
15. **git diff** — сравнение версий файлов
16. **git blame** — отслеживание изменений в файле
17. **git cherry-pick** — перенос отдельных коммитов
18. **git fetch** — получение изменений без слияния
19. **git remote** — управление удаленными репозиториями
20. **git tag** — создание меток в истории
21. **git revert** — отмена коммита через новый коммит

### Дополнительные полезные команды

22. **git config** — настройка параметров Git
23. **git clean** — удаление неотслеживаемых файлов
24. **git grep** — поиск по содержимому репозитория
25. **git show** — просмотр деталей коммита
26. **git bisect** — поиск коммита, вызвавшего проблему
27. **git blame** — отслеживание изменений в строках файла
28. **git mv** — перемещение файлов с отслеживанием истории
29. **git rm** — удаление файлов с отслеживанием
30. **git worktree** — управление несколькими рабочими директориями

### Полезные флаги и опции

* **--all** — показывать все ветки
* **--oneline** — компактный вывод истории
* **--graph** — графическое представление истории
* **--verbose** — подробный вывод
* **--interactive** — интерактивный режим
* **--dry-run** — проверка без выполнения

### Рекомендации по изучению

1. Начните с базовых команд (первые 11)
2. Постепенно добавляйте продвинутые команды
3. Изучайте команды по мере необходимости
4. Практикуйте использование команд в реальных проектах
5. Создавайте шпаргалки с часто используемыми командами

### Полезные комбинации

* **git add . && git commit -m "Сообщение"** — быстрое сохранение изменений
* **git pull origin main** — получение последних изменений
* **git push origin main** — отправка изменений
* **git status -s** — краткий статус репозитория
* **git log --graph --oneline** — наглядная история коммитов
