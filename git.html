50 практических задач по Git

Этот учебник предназначен для отработки команд Git в терминале VS Code. Все файлы создаются вручную, а команды вводятся последовательно.

Базовые операции

1. Инициализация репозитория

Цель: создать новый локальный репозиторий.

mkdir git-practice
cd git-practice
git init

После выполнения появится папка .git.

2. Добавление файла и первый коммит

Цель: научиться фиксировать изменения.

echo "Hello Git" > readme.txt
git add readme.txt
git commit -m "Добавлен readme.txt"

3. Проверка статуса

Цель: увидеть состояние файлов.

git status

4. Просмотр истории коммитов

Цель: научиться читать историю изменений.

git log

5. Изменение существующего файла

Цель: понять цикл изменения файла.

echo "Добавил строку" >> readme.txt
git add readme.txt
git commit -m "Обновлён readme.txt"

6. Создание ветки

Цель: научиться работать с ветками.

git branch feature
git switch feature

7. Слияние веток

Цель: объединить изменения.

git checkout main
git merge feature

8. Разрешение конфликта

Цель: научиться решать конфликты.

git add readme.txt
git commit

9. Удаление ветки

Цель: очистить репозиторий от ненужных веток.

git branch -d feature

10. Создание и переключение в одной команде

Цель: ускорить создание веток.

git switch -c dev

11. Добавление нескольких файлов

Цель: добавить все изменения сразу.

git add .
git commit -m "Добавлены новые файлы"

12. Просмотр краткого лога

Цель: компактно просматривать историю.

git log --oneline

13. Отмена последнего коммита

Цель: исправить ошибку без потери данных.

git revert HEAD

14. Изменение последнего коммита

Цель: поправить сообщение или добавить файл.

git add файл.txt
git commit --amend -m "Исправлен коммит"

15. Сравнение изменений

Цель: понять, что изменилось.

git diff

16. Возврат файла к последней версии

Цель: отменить локальные изменения.

git restore readme.txt

17. Игнорирование файлов

Цель: исключить временные файлы из репозитория.

echo "node_modules/" >> .gitignore
git add .gitignore
git commit -m "Добавлен .gitignore"

18. Просмотр удалённых репозиториев

Цель: узнать, куда привязан проект.

git remote -v

19. Подключение удалённого репозитория

Цель: отправить проект на GitHub.

git remote add origin https://github.com/user/git-practice.git
git push -u origin main

20. Клонирование репозитория

Цель: скачать чужой проект.

git clone https://github.com/user/repo.git

21. Получение изменений

Цель: обновить локальную копию.

git pull

22. Отправка изменений

Цель: загрузить коммиты в удалённый репозиторий.

git push

23. Смена имени ветки

Цель: переименовать ветку.

git branch -m old-name new-name

24. Удаление файла из отслеживания

Цель: убрать файл из индекса, не удаляя его физически.

git rm --cached файл.txt

25. Просмотр автора изменений

Цель: определить, кто изменил строку.

git blame readme.txt

26. Перенос коммита (cherry-pick)

Цель: применить конкретный коммит из другой ветки.

git cherry-pick <hash>

27. Переписывание истории (rebase)

Цель: сделать историю линейной.

git rebase main

28. Прерывание rebase

Цель: отменить процесс rebase.

git rebase --abort

29. Слияние без fast-forward

Цель: сохранить структуру веток.

git merge --no-ff feature

30. Создание тега

Цель: отметить релиз.

git tag v1.0
git push origin v1.0

31. Удаление тега

Цель: удалить ненужный тег.

git tag -d v1.0

32. Использование stash

Цель: временно сохранить изменения.

git stash
git stash pop

33. Список stash

Цель: посмотреть все сохранённые состояния.

git stash list

34. Удаление stash

Цель: очистить временные изменения.

git stash clear

35. Сброс коммитов (soft reset)

Цель: вернуть изменения в рабочее состояние.

git reset --soft HEAD~1

36. Полный сброс (hard reset)

Цель: удалить последние изменения.

git reset --hard HEAD~1

37. Проверка различий между ветками

Цель: сравнить содержимое двух веток.

git diff main feature

38. Проверка последнего коммита

Цель: увидеть, какие файлы были изменены.

git show

39. Создание алиаса

Цель: сократить часто используемые команды.

git config --global alias.st status

40. Настройка имени и email

Цель: установить данные автора.

git config --global user.name "Имя"
git config --global user.email "email@example.com"

41. Просмотр настроек

Цель: убедиться в правильной конфигурации.

git config --list

42. Удаление коммитов до определённого

Цель: вернуть проект к старому состоянию.

git reset --hard <commit_hash>

43. Поиск по истории

Цель: найти коммит с нужной строкой.

git log -S "строка"

44. Bisect (поиск бага)

Цель: найти коммит, вызвавший ошибку.

git bisect start
git bisect bad
git bisect good <commit>

45. Архивация репозитория

Цель: создать архив проекта.

git archive --format=zip HEAD > project.zip

46. Подмодули (submodules)

Цель: добавить внешний репозиторий внутрь проекта.

git submodule add https://github.com/user/lib.git libs/lib

47. Инициализация подмодулей

Цель: скачать содержимое подмодулей.

git submodule update --init --recursive

48. Удаление подмодуля

Цель: удалить подмодуль полностью.

git submodule deinit -f libs/lib
rm -rf .git/modules/libs/lib
git rm -f libs/lib

49. Создание патча

Цель: экспортировать изменения в файл.

git format-patch -1 HEAD

50. Использование Git Hooks

Цель: автоматизировать действия при коммитах.

#!/bin/sh
echo "Проверка перед коммитом..."

Создайте файл .git/hooks/pre-commit, вставьте этот код и сделайте его исполняемым.
